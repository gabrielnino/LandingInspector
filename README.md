# LandingInspector
LandingInspector: Landing page ligera e interactiva para diagnóstico de marcas y webs. Incluye un motor de auto-auditoría en tiempo real de 12 puntos, JS vanilla sin dependencias, diseño responsive con design tokens en CSS y captura de leads integrada con Web3Forms y WhatsApp. Creada por Luis Niño Developer para emprendedores.

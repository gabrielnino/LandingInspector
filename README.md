# LandingInspector 🔍

> **Landing page interactiva con herramienta de auto-auditoría para diagnóstico de marca y conversión web.**

**LandingInspector** es una solución web ligera, ultra-rápida y orientada a la conversión, diseñada para emprendedores hispanos. Incorpora una herramienta dinámica de auto-evaluación en tiempo real que permite a los usuarios diagnosticar problemas comunes en su marca, experiencia de usuario (UX) y optimización técnica antes de solicitar una auditoría personalizada.

---

## ✨ Características Principales

- 🎯 **Auto-auditoría interactiva en vivo:** Evaluación basada en 12 señales de alerta (marca, confianza, landing page y aspectos técnicos) con cálculo dinámico de score y diagnóstico instantáneo.
- ⚡ **Cero dependencias pesadas:** Construido con HTML5, CSS3 vanilla (utilizando *design tokens* nativos) y JavaScript Vanilla puro. Carga ultrarrápida sin *frameworks* adicionales.
- 📱 **Diseño Responsive & Fluid:** Adaptación impecable en dispositivos móviles y de escritorio mediante CSS Grid y Flexbox.
- 📩 **Captura de Leads Dinámica:** Integración ligera mediante **Web3Forms** para envío de formularios sin servidor (serverless), adjuntando automáticamente el puntaje de la auto-auditoría previa del usuario.
- 💬 **Integración con WhatsApp:** Canal secundario directo para acelerar el contacto con clientes potenciales.
- ♿ **Accesibilidad & UX:** Soporte para preferencias de movimiento reducido (`prefers-reduced-motion`) e interacciones basadas en *Intersection Observer* para animación progresiva (*scroll reveal*).

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3 (Custom Properties), JavaScript Vanilla (ES6+)
- **Tipografía:** Google Fonts (`Sora` + `Inter`)
- **Procesamiento de Formularios:** Web3Forms API
- **Arquitectura:** Single File Component / Static Single-Page Application (SPA)
